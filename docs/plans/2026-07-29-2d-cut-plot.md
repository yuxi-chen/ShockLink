# 2D Cut and Pressure Plot Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add `get_2d_cut()` and `plot_2d_cut()` to the flat Tecplot module, with an equatorial default cut and pressure-colored PyVista plotting.

**Architecture:** Use PyVista's dataset slice filter for plane/cell intersection and interpolation. Store normalized plane metadata on the returned `PolyData`, then use that metadata to orient a reusable PyVista plotter perpendicular to the cut.

**Tech Stack:** Python 3.11+, NumPy, PyVista 0.48+, pytest, the local BATSRUS Tecplot sample.

---
