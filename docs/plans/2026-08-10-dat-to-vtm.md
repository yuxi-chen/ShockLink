# Tecplot DAT to VTM Converter Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a standalone `tools/convert_dat_to_vtm.py` command that writes every PyVista-read Tecplot zone to a VTM multiblock file without modifying the dataset.

**Architecture:** Keep the tool self-contained and import only PyVista and the Python standard library. Expose a small `convert()` function for focused tests and a thin `main()` CLI wrapper. The conversion path will validate paths, call `pyvista.read()`, require `MultiBlock`, call `save()` directly, and optionally unlink the input after a successful save.

**Tech Stack:** Python 3.11+, PyVista 0.48+, argparse, pathlib, pytest.

```python
def test_convert_preserves_all_zones_and_default_output(tmp_path):
    source = _write_two_zone_dat(tmp_path / 'sample.dat')

    result = converter.convert(source)

    output = tmp_path / 'sample.vtm'
    assert output.is_file()
    assert isinstance(result, pv.MultiBlock)
    reloaded = pv.read(output)
    assert reloaded.n_blocks == 2
    assert reloaded.get_block_name(0) == 'zone-a'
    assert reloaded.get_block_name(1) == 'zone-b'
    for actual, expected in zip(reloaded, result, strict=True):
        assert type(actual) is type(expected)
        np.testing.assert_allclose(actual.points, expected.points)
        np.testing.assert_allclose(actual['rho'], expected['rho'])
```
